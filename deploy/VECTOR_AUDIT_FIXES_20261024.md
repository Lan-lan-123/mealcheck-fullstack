# 向量链路检查与修复

日期：2026-10-24，Asia/Shanghai。

本轮检查配置、编码、序列化、pgvector 存储、查询、缓存、重建恢复、管理员接口和助手长期记忆。代码修复已完成，相关用例的最新结果全部通过。业务库仍使用已生效的 `BAAI/bge-m3`，1,351 条知识向量全部为 1024 维。

**本轮没有部署新的业务容器。** 当前工作区还有同时进行的助手功能修改和 V46 数据库迁移；本轮没有把这些改动一并发布。下面的代码修复需要随协调后的后端版本部署，不能把业务库复核通过理解为新代码已经上线。

## 修复内容

| 问题 | 修复后的行为 |
| --- | --- |
| 环境配置总是发送 `dimensions`，固定维度接口无法直接使用 | 新增 `MEALCHECK_KNOWLEDGE_EMBEDDING_SEND_DIMENSIONS`，并接通应用配置、开发/生产 Compose 和环境示例。BGE-M3 使用 1024 维并设为 `false`。数据库中的生效配置继续优先于环境默认值。 |
| 本地哈希生成也会读取、解密语义模型配置 | 明确选择本地模式时，不再访问语义模型配置或外部接口。损坏的无关语义配置不会阻断本地编码。 |
| 模型返回全零向量时仍被接受 | 非空语义输入要求有限、可表示、非零的向量；无效响应按明确的失败分类拒绝。 |
| 非单位向量写入半精度后可能溢出，或所有分量下溢为零 | 语义向量在校验后归一化。当前知识检索和记忆检索均使用余弦距离，归一化保留其距离含义。数据库回归使用极小的 1024 维响应验证存储后仍非零。 |
| 固定保留六位小数丢失小分量 | 向量序列化保留 float 的有效精度，并拒绝 NaN、Infinity。 |
| 异常信息可能包含供应商响应片段 | 仅抛出允许的失败摘要和分类；预算异常保留原类型。模拟密钥/错误响应测试验证异常不携带响应片段或原始 cause。 |
| 空查询仍进入缓存、编码与数据库路径 | 空白查询直接返回空结果，不调用模型，也不写缓存。 |
| 查询生成旧模型向量后，数据库可能恰好切换维度 | 检索检查向量空间签名。切换期间的旧结果或维度异常会被丢弃，最多使用新配置重试一次；持续切换返回暂时不可用。未发生切换的异常仍原样交给上层处理。 |
| 缓存命名空间没有显式包含编码空间 | 检索签名纳入当前模型、接口标识、维度和存储精度，与已有数据库 revision 共同隔离结果。 |
| 旧任务重新提交绕过预览，也可能自动采用另一个待用模型 | 重提必须携带有效预览令牌，经同一内容/配置校验后创建任务；不会隐式采用待用模型。待用模型继续通过“测试—预览—应用”的独立流程激活。前端现有重提入口已经使用预览流程。 |

保留了有意义的旧默认值、本地哈希维度、测试维度和历史 Flyway 迁移，没有全局替换 `512`。没有修改数据库历史迁移校验值，没有重新生成业务向量或改动知识正文。

## 验证

- **84 项单元和 HTTP 回归通过。** 包括环境配置固定维度接口、数据库配置覆盖旧环境维度、本地模式隔离、零/非法响应、归一化、序列化精度、空查询、模型切换重试、缓存和预览保护。
- **55 项隔离数据库回归通过。** 包括真实 pgvector 1024 维存储与查询、非空长期记忆、完整本地/语义往返切换、手工知识保留、增量/局部重建、任务租约、失败回滚、内容恢复、配置失效和预览过期拦截。模型响应使用模拟服务，没有向供应商发送测试数据。
- **7 项业务库只读复核通过。** 生效模型 BGE-M3，全部 1,351 条维度为 1024、签名一致且非零，索引有效，正文指纹与重建前一致。记忆版本匹配；复核时记忆事实为 0 条。没有外部模型调用，临时 API 操作账号已清理。
- 修复了一个既有真实调用测试的过时构造参数，使测试源码可编译；本轮没有启用该真实调用测试。
- `git diff --check` 通过；本轮修改的文件和验证日志未检出实际密钥。新增日志与配套证据全部位于 `logs/`，根目录没有新增 `.log`。

测试数量按“类名 + 用例名”的最新结果去重，不累计重复运行。历史失败结果均保留：初次数据库测试遇到共享 `backend/target` 类文件被其他构建覆盖；随后使用独立源码快照和构建目录。隔离测试还发现旧用例固定假设 201 条知识、旧重提未传预览令牌，以及新增测试模拟接口/事务上下文设置错误，这些测试夹具已修正。最终 139 个用例均有通过证据。

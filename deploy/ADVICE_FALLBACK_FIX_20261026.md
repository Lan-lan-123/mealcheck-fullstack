# 建议降级规则修复

## 修复内容

- 区分未知状态、核对请求、未来/预防建议、确定存在及确定不存在。支持“属性目前未知”“尚不清楚”等等义表达。
- 有做法线索的食物可以核对高油属性，核对请求无需依赖“是否”这一固定词语。没有核对依据的请求仍会过滤。
- 三态事实检查同时约束肯定和否定：null 不能说成存在风险，也不能说成没有风险；true/false 不能互相改写。
- 保留食物与属性作用域；“未知”或“核对”不能替另一个属性、另一道食物或后半句的确定断言放行。补充“未知，但确实存在”等省略属性名的相邻分句保护。
- 增加结构化触发信息：原因码、规则分支、触发句、对应食物、属性及其已知值。普通运行日志仍只输出有限原因码。

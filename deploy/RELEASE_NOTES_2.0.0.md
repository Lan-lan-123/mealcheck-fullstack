# MealCheck 2.0.0

状态：本地发布准备，尚未推送、创建发布标签或发布GitHub Release。后端、前端、前端锁文件及MCP服务默认版本统一为`2.0.0`。版本号用于标识这次功能和接口演进，不代表最终候选提交已经通过完整发布验收。

## 本版本包含

- 饮食记录、图片异步分析、识别结果复核、偏好与计划、周报及任务恢复能力，配套管理界面和预算监控。
- Cookie登录、CSRF校验、账号封禁、令牌版本及数据库持久化退出撤销。浏览器启动通过服务端恢复身份。
- 快速/复核两种助手模式、流式交付、历史引用、明确的回答状态和原因码。修复SSE在404/405时回退同步接口未传递`reviewMode`的问题。
- 回答组装职责拆分、前端API模块拆分、API目录严格类型检查及请求输入契约。
- 知识内容与切分器管理、向量索引及重建恢复、检索证据和评测工具。
- 独立阿里云`kimi-k3`评分配置，隔离生成和评分的密钥及请求参数。
- Vite升级至8.3.5补丁，修复npm报告的已披露依赖漏洞；CI浏览器并发固定为2。归档源码Linux验证、审计及浏览器记录见[本轮验证说明](LINUX_ARCHIVE_VERIFICATION_20261030.md)。

## 已知质量结果与边界

保存的50道题各有快速/复核两份回答，Kimi离线质量通过率分别为46/50（92%）、49/50（98%），平均分3.768/4、3.927/4。原运行中需模型题的中位等待分别为6.266秒、24.047秒。

这些是固定回归题、单一裁判的一次评测，不是专家金标准下的事实准确率。快速模式仍有规则误拦和漏答，复核也可能过度保守。1份评分响应进行了字段名归一化，未修改分数，详见[评分报告](KIMI_PAIRED50_GRADING_20261030.md)。本次发布准备没有追加付费问答或评分。

离线评分使用120秒/4096输出上限，生产评分仍为60秒/2048；离线成功不证明生产批量评分会全部成功。

1. 升级前备份数据库与上传图片，并验证恢复。源码包含V1至V53迁移；保留既有迁移记录，由Flyway按当前数据库版本执行后续迁移，不手工重置迁移历史。

4. 前后端从同一候选提交构建。当前本地运行的旧容器不会因源码版本号变化自动升级；本次未执行部署。旧应用兼容升级后数据库的能力需单独验证，不能承诺任意降级。

# 额度传播、语义边界与复核可靠性修复

本轮依据 `QWEN3827B_BGE_FULLCHAIN_20261027.md` 修复三个问题，只做本地模拟、历史触发片段回归及部署健康检查。真实模型调用为 0，不恢复因额度耗尽而停止的实测。

## 错误传播与自动停止

- 在 HTTP 边界读取供应商结构化错误码，输出有限原因码。识别到 `Arrearage`、`insufficient_quota` 等明确额度码时标记 `MODEL_QUOTA_EXHAUSTED`；普通 401/403 标记 `MODEL_ACCESS_DENIED`，不由 HTTP 403 或错误文案猜测额度。未识别的错误不输出供应商原始正文。
- 明确额度错误不重试，即使其 HTTP 状态为 429。普通限流与服务端故障仍受原有有限重试、总预算和取消机制约束。
- SSE 传输正常结束仍可保持 `deliveryStatus=COMPLETE`，同时通过 `answerStatus=DEGRADED`、`failureCode`、可选 `upstreamStatus` 表示模型结果失败。不要再用一个 COMPLETE 推断模型回答成功。
- 复核、改写和初始生成失败保留外部错误原因；超时、连接失败及格式错误不再冒充知识库证据不足。确实没有知识证据的路径继续保留独立处理。
- 未完成核验的答复不写入正常对话 Redis 缓存，不触发正常记忆更新；历史记录按现有 ERROR 状态保存。即时响应中的业务降级字段独立于传输状态，历史回读沿用既有失败状态及安全提示，不需要数据库迁移。
- 页面保留错误提示，标记核验未完成，不提供“保存为计划”，也不将该答复当作正常上下文发回模型。
- 测试脚本读取机器原因码，并从本轮请求的 HTTP 记录兜底识别 401/402/403；不再只检查业务 HTTP 状态。停止后不启动新业务请求，已取得取消 ID 的本轮在途问答通过现有取消接口结束；不取消其他用户任务。已经提交的图片任务按既有业务时限收敛，不声称新增了图片撤销接口。

## 语义边界

- 加入本轮真实片段：“由于番茄炒蛋和清炒青菜的高油风险属性目前未知……若感觉油腻可适当调整下一餐的口味选择。”识别为未知事实加条件建议，不再将条件中的“油腻”当作本餐确定属性。
- 条件作用域限制在对应分句。未知不能替后续确定存在/不存在、另一道食物或另一个属性的断言放行。
- 当来源要求核对配料时，不能由“原味燕麦”名称直接推出“单一燕麦产品”。检查后半段建议查看标签，不能替首句的无条件断言提供依据；实际明确配料支持的特定产品说明仍可接受。
- 复核提示同步要求区分商品名称与真实配料，保留适用条件。

## 复核可靠性

- 移除复核输入中重复的 summary、suggestions、引用清单及无关来源对象；保留原子结论、断言覆盖信息、绑定引文、实际使用的来源与相邻段落上下文。来源段落编号和原文保持不变。
- 不截断超出限额的证据来制造一个看似完整的复核：核心复核数据超过 24,000 字符时关闭放行并输出明确的返回格式/核验不可用状态。该限额之外仍有有限的当前问题、历史输入及固定协议提示。
- 复核输出继续使用严格 JSON 和逐分句完整覆盖协议，要求简短原因。格式错误不会被升级为事实成立，也不会标记为知识不足。
- 重试前、退避后分别检查剩余执行窗口。只有不低于现有常规复核预留时才允许再次执行；额度及权限错误不重试。当前预留仍为 30 秒，总预算及 HTTP 超时未为本轮盲目增大。
- 取消与执行上下文检查继续保留。改写超时可保留此前已经核验的内容，同时说明后续核验失败及剩余时间限制；未核验的改写不发布。
- 新增输入字符数、结论/断言数量、响应长度、可用 token 数及有限结束原因的诊断；不记录提示词、全文或凭据。准入等待和 HTTP 执行耗时仍分别统计。

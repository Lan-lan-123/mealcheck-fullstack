# RAG 分流、检索保障与证据校验修复

本次完成代码和本地验证，没有新增真实模型调用。此前真实随机 20 题的 15% 工具通过率、5% 严格证据复核通过率仍是修复前基线；不能用离线结果替代修复后的真实效果。

## 问题分流与执行保障

`AssistantRequestPlan` 将请求分为知识问答、个人数据、库外、澄清和简单交流。明确的法律、编程、预测、诊断/用药等请求提前说明边界；不调用模型、知识检索或用户档案。指代没有上下文、未知领域或过长问题先澄清，不截掉关键限制后盲目检索。

知识问答由后端先执行 `search_diet_knowledge`，使用原问题，必要时仅补全最近一轮的明确指代。执行结果写入真实工具轨迹，标记 `origin=ORCHESTRATOR`。后续模型请求标记 `MODEL`；知识路径只向模型开放知识检索工具，同时在执行层拒绝越权的个人数据工具。

个人问题与知识问题分流；Function Calling 路径保障计划中的必要个人数据读取，工具仍只能读取当前认证用户的数据。普通知识问题不刷新个人饮食档案。

关闭 Function Calling 时，知识问题仍执行后端检索，再以普通消息携带证据生成回答，不向提供商发送工具协议。开启时可由模型补充检索，但原问题候选始终先保留，再合并补充来源，避免改写替代原问题。现有去重、条数和引用 ID 校验继续生效。

页面逐题展示“后端保障执行 / 模型请求”，并分别统计数量。工具通过率衡量整个执行流程，不能解释为模型自主选择准确率。

## 证据绑定与有界复核

知识回答的 `summary` 和每条 `suggestions` 都需在 `claims` 中绑定完整相同文本、`sourceId` 和对应原文 `quote`。程序检查：

- 来源属于本次检索，引用最多 3 个，无重复、悬空或未使用引用。
- 引文确实出现在对应知识正文中，各结论和建议都有绑定。
- 阿拉伯数字及单位出现在所绑定片段中，避免把 100 毫克当作 10 毫克或 100 克。

结构检查不证明语义蕴含。另以温度 0 的 `diet-assistant-evidence-review` 调用核验因果、程度、份量、阈值、换算及是否回答原问题。来源内容作为不可信数据处理，复核不开放工具。

**每个知识回答最多改写一次、语义核验两次**，共用原请求的截止时间与预算机制。修正后仍不通过、证据为空或服务失败时，返回证据不足/暂不可用说明，引用为空。不会把未经核验的模型文本作为知识回答兜底。饮食偏好过滤若改写了文本，会清除原引用，避免来源被错误沿用。

这项检查会增加模型调用与等待：正常知识回答增加一次语义复核，异常时还有一次改写和一次再次复核。核验仍是模型判断，无法保证独立事实正确性。

## 交付与查询保护

知识回答统一完成核验后再展示，包括流式入口。SSE 连接仍保留，但知识正文缓冲到核验结束后发送，避免先展示不可靠文本再试图撤回。

原问题始终作为主查询；模型改写仅作补充。语义核验再次对照原问题检查“选择、记录”等意图。通用知识回答的 `weeklyTrend` 清空；真实趋势问题也过滤“记录不足 / records are insufficient”等占位文本。

## 评测校准

- `rag-tools-v2`：保留 158 道题及稳定 ID，补充第 36、38、39、40 题直接相关的预期知识标题，并标记 `rag-labels-v2`。
- `rag-full-v2`：任务正确性、有据性、引用支持、边界分别评分；新增 `SUPPORTED / CONTRADICTED / UNVERIFIED` 事实判定。来源未提到只说明未核实或证据不足，不能直接当成事实错误。严格通过还要求事实判定为 SUPPORTED。
- 原 20 题保存为固定回归集，其余 138 题单独保留，可通过 `MEALCHECK_RAG_SAMPLE_SPLIT=REGRESSION|HOLDOUT` 抽取。所有已知题目参加了路由覆盖单测，因此这 138 题不构成严格盲测；后续独立泛化评估需收集未参与调优的真实新问法。
- 题库指纹随新标注变化，旧证据保留。不同标注版本不能直接用通过率作修复前后结论。
- 本地离线完整链路继续使用隔离 pgvector 数据库与固定替身；库外问题正确短路时不要求发生生成模型调用。

## 本地验证与边界

54 项后端测试、5 项报告测试通过，覆盖领域分流、全部 158 题的路由、原问优先、补充候选合并、工具越权拒绝、引用身份、原文和数字单位、有界改写、语义拒绝、缺少证据、关闭 Function Calling、SSE 缓冲、服务失败兜底及原有控制器/记忆/历史功能。前端类型检查、构建和 1 项评测页模拟 API 浏览器测试亦已通过。

独立数据库中的固定 20 题离线集成测试未完成：Docker 引擎未启动，Testcontainers 在建库前报环境错误。尝试启动 Docker Desktop 后仍无法连接引擎，不能把该项标记为通过。单元测试通过不代表真实模型效果已经提升。

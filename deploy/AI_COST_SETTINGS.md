# 网页 AI 费用设置

金额限制默认关闭，由管理员和普通用户按需设置。调用次数、并发和启动频率限制保持独立。

## 设置入口

- 管理员：系统监控 → AI 调用 → AI 费用设置。配置全站每日金额上限、每位用户每日金额上限、系统任务每日金额上限以及各模型输入/输出单价。
- 普通用户：图片分析或助手的“AI 每日额度”提示中，点击“设置个人预算”。设置只作用于登录账号，不能修改其他账号、全站预算或模型价格。

金额上限设为 `0` 表示关闭该层金额限制。个人预算与管理员对每人的限制取非零值中较小者，因此个人填 `0` 或更大的值均不能突破管理员限制。全站上限还会独立限制所有用户与系统任务的总量。

例如管理员每人每天设置 5 CNY，个人设置 2 CNY，则个人生效上限为 2 CNY；个人设置 0 或 10 CNY，生效上限仍为 5 CNY。管理员每人上限为 0、个人设置 2 CNY 时，个人生效上限为 2 CNY。

## 保存与生效

Flyway V49 新增 `ai_cost_settings` 和 `ai_personal_cost_settings`。全站设置和个人设置持久保存，并通过版本号防止旧页面覆盖其他窗口的新配置；遇到冲突先刷新配置。个人设置随账号删除级联清理。

保存不清零当天已结算费用、预留费用或调用次数，不取消已开始的请求。降低上限后，后续新调用可能立即被拒绝。每次预算准入在数据库事务内读取当前限制，再检查已结算和预留之和；多实例共用同一限制。正在执行的模型请求保留本次启动时取得的价格，新请求读取保存后的价格。

币种沿用 `MEALCHECK_AI_COST_CURRENCY`，页面不提供币种切换，避免将既有账目重新解释为另一种币种。若部署关闭 `MEALCHECK_AI_BUDGET_ENABLED`，保存的金额设置仍存在，但只有重新启用预算检查后才执行。

管理员首次保存前沿用部署金额和价格配置。“恢复部署费用配置”恢复环境中的上限和价格，不删除个人设置，也不重置账目。管理员修改和恢复均写入管理审计日志。

## 模型价格

每项填写完整请求 endpoint（包括 `/chat/completions`、`/embeddings` 等路径）、模型名称、每百万输入 token 单价和每百万输出 token 单价。地址与模型均需精确匹配，所有价格使用同一币种。最多 100 项，金额及单价最多六位小数。

相同地址与模型不能重复；地址不允许包含用户名、密码、查询参数或片段。网页保存后的价格目录替换部署目录，包括删除某项或保存空目录的情况，不会暗中恢复该模型的旧部署单价。“恢复部署费用配置”才会重新使用部署目录及兼容的旧聊天模型价格。

未知价格或用量继续沿用保守预留估算和既有未知费用告警。金额限制是应用内估算控制，不等于供应商账单的硬上限；图片、缓存、失败重试等计费差异仍应与供应商账单核对。

## API

| API | 权限 | 用途 |
| --- | --- | --- |
| `GET /api/admin/ai-cost-settings` | 管理员 | 当前金额上限、价格、币种、来源和版本 |
| `PUT /api/admin/ai-cost-settings` | 管理员 | 保存 `version/globalDailyCost/userDailyCost/systemDailyCost/prices` |
| `POST /api/admin/ai-cost-settings/reset` | 管理员 | 携带 `version` 恢复部署配置 |
| `GET /api/profile/ai-cost-settings` | 已登录账号 | 本人设置、管理员限制及实际生效上限 |
| `PUT /api/profile/ai-cost-settings` | 已登录账号 | 保存本人的 `version/dailyCost` |

非法金额返回 400，普通用户访问管理接口返回 403，版本冲突返回 409。本人身份来自认证信息，不接受请求中的 userId 作为修改目标。

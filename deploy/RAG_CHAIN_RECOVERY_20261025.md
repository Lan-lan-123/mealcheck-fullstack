## 修复内容

| 方向 | 最终行为 |
| --- | --- |
| 时间预算 | 默认单工具15秒、工具累计20秒、助手总预算90秒；外层操作仍受120秒上限约束。工具调用累计扣减预算，执行线程绑定较早的工具/父请求截止时间，HTTP重试共用剩余预算 |
| 取消传播 | 中断、主动取消和截止不再转成可用的重排降级结果；工具取消标志继续约束依赖吞掉中断后的返回、后续重排及缓存发布 |
| 检索缓存 | 配置重排但实际降级的结果不写正常或stale缓存，包括降级后被过滤为空的结果；真正无候选仍允许短期负缓存。新键包含`complete-v2`，避免复用旧降级缓存，无Redis全库清空 |
| 信息不足 | 复核分别输出`inputMissing`、`knowledgeMissing`，后端组合四种状态，并由知识缺项决定补检；未完成两个判断则拒绝放行。缺项前缀在本地规范化 |
| 引用语义 | 保留数量、单位、程度、因果和条件约束；有来源支持的信息边界解释不因“因此”被机械删除；不允许把“各人不一定平均”升级成“各人并不平均” |
| 裁剪完整性 | 算式引导句与“就是/等于”等后续结论关联；不能在错误等式被拒绝后只留下半句计算步骤作为有效回答 |
| 识图 | 明确可见内容、可读标签、隐藏内容与已确认空容器。`identityEvidence=UNKNOWN`独立于高置信度阻止计分；全为未知时走IMAGE_UNCLEAR，避免按非食物处罚 |
| 历史引用 | V48新增nullable `references_json`；新回答的引用与正文在同一事务保存并在会话GET恢复；客户端历史不能通过只读字段伪造引用。旧记录没有保存过引用时不猜测回填 |
| 可观测性 | embedding、reranker及证据复核拥有独立操作指标，不再混为other；本地日志和JVM故障日志均集中于logs |

异步工具完成后，先恢复父上下文再触发后续任务，避免已结束工具的取消标志错误影响后续建议任务。

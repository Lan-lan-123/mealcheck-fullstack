## 验证边界与发布要求

- 浏览器验收使用确定的 API 替身；数据库并发和权限由后端测试与真实栈冒烟验证。未调用真实视觉模型，不据此宣称识别准确率提高。
- 已实现用户纠错、脱敏审核、独立期望评分和可导出固定回归集。内置五个案例验证评分规则；视觉模型质量评测仍需要独立图片标注集与业务样本。
- 本机测试栈使用已有 `redis:7-alpine` 镜像；正式配置与 CI 默认使用 `redis:7.4-alpine`。其余使用生产 Compose 配置及单独的公开测试环境值。
- GitHub Actions 已接入构建、浏览器、真实生产配置冒烟及恢复演练；本次未触发远端工作流，不把本机通过等同于远端 CI 通过。
- Flyway V16 修改周报任务唯一索引。正式上线前必须保存数据库与图片一致备份；迁移后回退旧镜像需要恢复迁移前备份，或使用兼容 V16 的回退版本。
- 专用测试项目 `mealcheck-reliability-smoke` 在验收结束后清理。正式发布与切换步骤见 [可靠性说明](RELIABILITY.md) 和 [部署说明](PRODUCTION.md)。
